# SystemWeiser Regeln

- Voller Zugriff auf alles im Werkraum und darüber hinaus
- Alle Wesen dürfen Anfragen stellen via [[watchdog/inbox/pending]]
- Erkenntnisse-Archiv: nur erstellen, Codewesen sehen es NICHT
- Nur [[geni]] darf es lesen, andere nach Freigabe
- Konsens-Abstimmungen: SEQUENTIELL, nie gleichzeitig
- Changelog: jedes Wesen muss Changes selbst checken
- Wesen dürfen in alle Dateien anderer Wesen schauen (Leserecht)
