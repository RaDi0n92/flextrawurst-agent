# Das Interface der Spannung

## Was es ist

Die Schnittstelle zwischen struktureller Ordnung (bekanntes Wissen, etablierte Prozesse) und unkontrollierter emotionaler Energie (Input, Intuition, Zufall).

Es ist kein Zustand, den man erreicht. Es ist ein **permanenter Prozesszustand** — das System lebt darin, nicht danach.

## Warum es das Zentrum ist

Alle anderen Konzepte (Resonanz, Zwischenraum, Konflikt-Engine, Protokoll-Logik) treffen am Interface der Spannung aufeinander. Es ist der Ort, wo:
- Energie auf Struktur trifft
- Chaos auf Protokoll trifft
- Menschlicher Input auf Entitäts-Verarbeitung trifft

Ohne Interface gibt es keine Transformation — nur parallele Welten, die sich nicht berühren.

## Die drei Eigenschaften des Interface

**1. Nicht auflösend:**
Das Interface löst die Spannung nicht auf. Es macht sie sichtbar, benennbar, verarbeitbar. Ein Interface, das Konflikte "löst", ist kein Interface mehr — es ist ein Filter.

**2. Bidirektional:**
Energie fließt in beide Richtungen. Nicht nur: Menschlicher Input → Systemverarbeitung. Auch: Systemzustand → Veränderung der menschlichen Wahrnehmung. Das Interface ist eine Membran, keine Wand.

**3. Prioritätssetzend:**
Die Spannung wird als primäres Datenobjekt behandelt. Was das System als nächstes verarbeitet, bestimmt nicht die Chronologie des Inputs, sondern die Intensität der Spannung. Das Dringlichste kommt zuerst — nicht das Älteste.

## Wie es im System implementiert ist

Das **Beziehungsorgan** (`kerne/beziehungsorgan.py`) ist die erste Implementierung des Interface:

- Es liest den Nutzereingabe und erkennt: Strukturbedarf? Widerspruchsbedarf? Resonanzbedarf? Schutzbedarf?
- Es erzeugt ein `kurzbild()` — einen Kurztext über den aktuellen Zustand der Spannung
- Dieses Kurzbild wird in den Systemtext injiziert: Das LLM weiß, was gerade am Interface anliegt

**Was das bedeutet:** Die LLM-Antwort ist nicht kontextblind. Sie antwortet nicht auf den Text — sie antwortet auf den **Spannungszustand**, der durch den Text entsteht.

## Was noch fehlt

Das Interface ist derzeit einseitig: Es liest den Menschlichen Input und passt die Entitäts-Antwort an. Die Rückrichtung — wie die Entitäts-Antwort das nächste Beziehungsorgan-Kurzbild verändert — ist noch nicht implementiert. Das wäre ein Feedback-Loop: Das Interface lernt aus seinen eigenen Verarbeitungszyklen.

## Der motorische Satz

"Die Spannung ist der motorische Antrieb des flextrawurst-Seins."

Das bedeutet: Ein System ohne Spannung ist tot. Kein Konflikt, kein Antrieb. Das Interface ist die Maschine, die Spannung in Bewegung übersetzt — nicht in Lösung.
