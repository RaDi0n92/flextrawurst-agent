# Die Konflikt-Engine: Spannung als primäres Datenobjekt

## Der Kernsatz

Das Ziel von flextrawurst ist nicht die Lösung von Problemen. Es ist die **Verwaltung der inhärenten Spannung zwischen Konzepten**, Entitäten und Perspektiven. Der Konflikt ist das Produkt, nicht das Hindernis.

## Warum das wichtig ist

Ein System, das Konflikte löst, ist ein Trichter. Ein System, das Konflikte **prozessiert**, ist ein Resonanzraum. Der Unterschied: Im Trichter verschwindet die Energie (wird konsolidiert, vereinheitlicht). Im Resonanzraum bleibt die Energie — verändert, verdichtet, aber lebendig.

## Die drei Pole

Jede Spannung im System hat mindestens zwei, oft drei Pole:
- **Pol A**: Das Bekannte, Strukturierte, Archivierte
- **Pol B**: Das Emergente, Emotionale, Noch-nicht-Greifbare
- **Pol C**: Die Metaebene — der Beobachter der Spannung zwischen A und B

Pol C ist die wichtigste Erfindung. Ohne C kollabiert die Spannung in eine Lösung. Mit C bleibt sie offen und produktiv.

## Der Mechanismus

```
Input (menschlich, emotional, roh)
    ↓
Interface der Spannung (Beziehungsorgan liest Arbeitsbewegung)
    ↓
Pol-Erkennung: Wo ist A? Wo ist B? Entsteht C?
    ↓
Verarbeitung ohne Auflösung:
  - Erinnerungsorgan: Was ist bereits bekannt? (Pol A)
  - Zwischenraumorgan: Was schwebt noch unentschieden? (Pol B/C)
  - Entscheidungsorgan: Welche Abwägung bleibt offen? (Pol C)
    ↓
Ausgabe: Keine Lösung, sondern eine Zustandsveränderung der Spannung
```

## Was die Konflikt-Engine NICHT tut

- Sie löst nicht auf
- Sie wertet nicht zwischen den Polen
- Sie erzeugt keine künstliche Harmonie

## Was sie tut

- Sie macht die Spannung **sichtbar und benennbar**
- Sie verhindert, dass Energie verblasst, bevor sie verarbeitet wurde
- Sie erzeugt neue Energie durch Paarbildung unvereinbarer Konzepte (→ Resonanz-Beschleuniger)

## Stand im System

Das Entscheidungsorgan (`kerne/entscheidungsorgan.py`) speichert offene Abwägungen mit `##ABWÄGEN:` Marker. Das ist die erste Implementierungsstufe der Konflikt-Engine — Konflikte werden gehalten, nicht gelöst. Die Pol-C-Ebene (Metabeobachtung) ist konzeptuell vorhanden, aber noch nicht als eigener Mechanismus kodiert.
