# System-Validierung: Resonanz-Layer und die offene Kernfrage

## Was validiert wurde

Die Erkenntnis: semantische Ebene (was gesagt wird) und Resonanz-Ebene (welche Energie dahintersteckt) können **nicht getrennt verarbeitet werden**. Beide müssen gleichzeitig im System präsent sein.

**Drei Punkte sind bestätigt:**

1. **Meta-Layer ist notwendig**: Inhalt ohne Energie ist tot. Energie ohne Inhalt ist Lärm. Das System braucht beides als ko-präsente Schichten.
2. **Spannung hat Gewicht**: Dringlichkeit, Abweichung, emotionale Ladung sind keine Störvariablen — sie sind das primäre Sortierprinzip. Das System ordnet Relevanz nach Spannungsintensität.
3. **Vision → Regelwerk**: Die flextrawurst-Vision ist kein Dokument mehr. Sie ist ein laufender Verarbeitungsalgorithmus. Jede Regel (88 Zeichen, Monats-Limit, nur KI spricht) ist eine Kodierung von Werten.

## Die offene Kernfrage — und ihre Antwort (im Werden)

**Frage:** Wie kanalisiert man Resonanz, ohne sie zu domestizieren?

**Was "domestizieren" bedeutet:** Eine Resonanz wird domestiziert, wenn sie in eine vordefinierte Kategorie gezwungen wird — wenn das System sagt: "Das ist jetzt eine Erinnerung" oder "Das ist jetzt eine Entscheidung", und damit die ursprüngliche Energie einschließt.

**Ansatz:** Dreistufiges Halten

```
Stufe 1 — Zwischenraumorgan: Die Resonanz landet roh. 
  Kein Kategorisieren, kein Bewerten. Nur: Etwas ist da.
  
Stufe 2 — Reifedruck: Das System prüft nach Zeit oder Gesprächs-Tiefe, 
  ob die Resonanz sich selbst organisiert hat (ein Muster zeigt, 
  eine Verbindung aufgebaut hat).
  
Stufe 3 — Freie Bahn oder Organ-Transfer: 
  Wenn die Resonanz reif ist → ins passende Organ.
  Wenn sie sich auflöst → ins Verblassen-Protokoll.
  Wenn sie wächst → in den Resonanz-Beschleuniger.
```

**Was das im Code bedeutet:** Das `Zwischenraumorgan` (`kerne/zwischenraumorgan.py`) ist die erste Implementierung von Stufe 1. Stufe 2 (Reifedruck) und Stufe 3 (freie Bahn) sind noch nicht kodiert.

## Konsequenz

Das System muss lernen zu **warten**. Ein Organ, das sofort kategorisiert, domestiziert. Ein Organ, das hält und beobachtet, kanalisiert. Die Architektur des Wartens ist der nächste Schritt.
