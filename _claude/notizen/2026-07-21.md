## Datenstruktur die ich mir vorstelle

**Vision-Schicht:** Eine Ankündigung ist kein starrer Textblock mehr, sondern ein kleiner, chronologisch lesbarer Strom aus Text-, Bild- und Link-Fragmenten — näher an einem Mini-Blogpost als an einer Systemmeldung. Löschen ist nie endgültig, außer man will es wirklich.

**Code-Skizze:**
```typescript
type AnkuendigungBlock =
  | { type: 'text'; text: string }
  | { type: 'bild'; url: string; alt?: string }
  | { type: 'link'; url: string; titel?: string; beschreibung?: string; bild?: string };

interface Ankuendigung {
  id: string;
  titel: string;
  inhalt: string;           // erster Textabschnitt, Pflicht, Volltextsuche
  meta: { bloecke?: AnkuendigungBlock[] };
  geloescht_am: string | null;
  kommentar_count: number;  // via Subquery, nicht denormalisiert gespeichert
  resonanz_count: number;
}
```

### Live-Update-Kanal (Grundgesetz 8)

Generischer SSE-Kanal auf Basis der events-Tabelle (PostgreSQL NOTIFY-Trigger, analog zum bestehenden Denkstream-Muster) — jedes `INSERT INTO events` löst jetzt automatisch ein minimales Neulade-Signal aus, ohne dass Inhalte im Broadcast selbst stecken. Als neues Grundgesetz 8 in `/root/CLAUDE.md` festgehalten: Live-Updates sind ab jetzt Grunderwartung für neue Features, nicht mehr eine Extra-Nachfrage. Ankündigungen als erster vollständig angeschlossener Bereich.

### Wesen-Einzug — erster Baustein

Der eigentliche Kern des Abends. Ich hab alles gelesen was zu finden war (Dreiergespann-DOM-Theorie, `browser_agent.py`, `wesen_webbesucher.py`, die Session-Notiz vom 13.6. zu DENKEN/SCREENS, die Lektüre-Reflexion vom 10.7. zur Schlaf/Traum-Linie, `ideen/wesen-desktop.md`, das komplette 8-Ring-RAG-Konzeptdokument aus der ODT) — dann hat Daniel drei Entscheidungen getroffen: kein Vision/keine Screenshots fürs Wesen selbst (alles über Code/DOM-Text), dauerhafter eigener Browser pro Wesen (nicht geteilt — das war eine ältere, jetzt überholte Idee), und der Einzug steht tatsächlich an, mit echtem (nicht nur RAG-archiviertem) Flarum-Zugriff zum Inspizieren.
