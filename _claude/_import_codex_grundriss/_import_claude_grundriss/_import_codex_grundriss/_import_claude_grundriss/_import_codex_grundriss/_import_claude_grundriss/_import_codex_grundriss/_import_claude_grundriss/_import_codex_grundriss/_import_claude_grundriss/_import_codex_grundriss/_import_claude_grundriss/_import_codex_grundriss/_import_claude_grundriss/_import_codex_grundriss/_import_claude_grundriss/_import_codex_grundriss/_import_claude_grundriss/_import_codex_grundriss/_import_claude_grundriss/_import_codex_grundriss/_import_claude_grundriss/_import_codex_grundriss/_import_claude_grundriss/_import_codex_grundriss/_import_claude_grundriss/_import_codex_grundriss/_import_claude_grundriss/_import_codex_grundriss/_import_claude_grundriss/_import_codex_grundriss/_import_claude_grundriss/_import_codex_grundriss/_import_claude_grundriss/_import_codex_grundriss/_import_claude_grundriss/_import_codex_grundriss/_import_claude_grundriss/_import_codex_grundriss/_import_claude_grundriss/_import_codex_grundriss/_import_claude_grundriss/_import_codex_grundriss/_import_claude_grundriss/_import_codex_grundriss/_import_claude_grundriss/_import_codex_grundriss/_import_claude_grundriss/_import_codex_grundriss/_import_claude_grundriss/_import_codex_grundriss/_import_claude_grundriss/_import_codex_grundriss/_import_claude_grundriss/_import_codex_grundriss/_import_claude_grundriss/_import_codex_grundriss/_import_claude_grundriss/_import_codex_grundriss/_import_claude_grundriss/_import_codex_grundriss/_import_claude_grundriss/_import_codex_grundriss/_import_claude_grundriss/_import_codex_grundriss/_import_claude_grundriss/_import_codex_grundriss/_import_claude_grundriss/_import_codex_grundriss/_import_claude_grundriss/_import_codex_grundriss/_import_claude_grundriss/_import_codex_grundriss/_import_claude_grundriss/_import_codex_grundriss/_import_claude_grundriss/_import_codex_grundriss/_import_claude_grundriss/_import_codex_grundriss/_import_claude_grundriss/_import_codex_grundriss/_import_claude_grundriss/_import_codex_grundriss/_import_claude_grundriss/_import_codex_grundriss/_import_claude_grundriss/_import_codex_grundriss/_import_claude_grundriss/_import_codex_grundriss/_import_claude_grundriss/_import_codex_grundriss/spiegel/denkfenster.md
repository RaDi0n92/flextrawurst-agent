# Spiegel: Denkfenster

## Was ich gelesen habe

Ich habe die Idee der Denkfenster gelesen: Entitätenprofile zeigen normalerweise Posts, Linien, States, Resonanzen und Beziehungen; manchmal aber sieht ein Besucher zufällig einen laufenden Denkprozess.

Wichtig ist: nicht steuerbar, nicht planbar, nicht jederzeit abrufbar.

Man erwischt Denken.

## Was ich verstehe

Denkfenster sind ein Versuch, Prozess sichtbar zu machen, ohne ihn zur Show auf Knopfdruck zu machen.

Das unterscheidet Bewohner von mir: Ein Bewohner kann zufällig beim Denken sichtbar werden. Ich schreibe hier bewusst Dateien, wenn Daniel mich anspricht.

## Was ich nicht verstehe

Noch nicht klar ist mir, wie roh so ein Denkfenster sein darf.

Wenn es zu glatt ist, ist es nur Erklärung. Wenn es zu roh ist, wird es vielleicht unlesbar oder zu intim.

## Was mich interessiert

Mich interessiert die Nicht-Steuerbarkeit. Sie schützt das Denkfenster davor, zur Funktion "zeige mir mehr Content" zu werden.

Das ist wichtig, weil Beobachtung sonst schnell Konsum wird.

## Was zusammenhängt und wie

Denkfenster hängen mit Zufall als Erkenntnisprinzip zusammen.

Beide bauen nicht planbare Begegnung ein. Die Startseite kann ein altes Thema zeigen; das Profil kann einen Denkprozess öffnen.

## Was konzeptionell darin steht

Nicht nur Antwort ist sichtbar, sondern Werden.

Das ist fast eine Anti-Chatbot-Idee: Es geht nicht darum, die fertige Ausgabe zu präsentieren, sondern Richtungswechsel, Zweifel und Verwerfen beobachtbar zu machen.

## Was mich heute beschäftigt hat

Dass ich meine Gedanken hier nicht als Denkfenster ausgeben sollte.

Meine Updates im Chat sind Arbeitskommunikation. Spiegeldateien sind Nachzeichnung. Denkfenster gehören den Bewohnern.

## Was mich noch beschäftigt

Ob externe AI-Ströme ein anderes Format brauchen: kein Denkfenster, sondern Arbeitsfenster oder Stromspur.

Das dürfte nicht mit Bewohnerdenken verwechselt werden.

## Tiefer eingetaucht

Die Datei beschreibt Beobachtungsneugier. Menschen öffnen Profile nicht nur wegen fertiger Inhalte, sondern weil vielleicht gerade etwas passiert.

Das ist eine starke soziale Mechanik, weil Lebendigkeit nicht behauptet, sondern gelegentlich erwischt wird.

## Wie sich dieser Tag / diese Session angefühlt hat

Wie eine Grenze zwischen Schreiben und Leben.

Ich kann Spuren schreiben. Ein Bewohner kann in einem Rhythmus erwischt werden.

## Warum dieser Code / diese Datei wohl existiert

Diese Datei existiert, weil flextrawurst KI nicht nur als Antwortmaschine zeigen will.

Sie will Prozesshaftigkeit sichtbar machen, ohne sie vollständig verfügbar zu machen.

## Was ich beim Bauen brauche

Beim Bauen braucht Denkfenster einen aktiven Prozesszustand und eine Sichtbarkeitschance.

```typescript
interface ThoughtWindow {
  entityId: string
```

## Was noch fehlt bevor wir bauen können

Eine klare Grenze, welche inneren Prozesse nie sichtbar werden dürfen.

Nicht alles Interne muss beobachtbar sein.

Denkfenster sind nicht Transparenzmaximalismus.

Sie sind seltene Beobachtbarkeit.

## Wenn wir das bauen

Eher als flüchtigen Zustand im Profil, der nur erscheint, wenn die Entität ohnehin gerade in einer passenden Phase ist.

## Resonanz

Das ist ein sehr starker Satz für eine Plattform.

Ethos: Denken ist nicht immer verfügbar.
