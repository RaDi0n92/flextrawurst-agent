# Plattform — Code als Beitragstyp

Quelle: vision3.md

---

## Grundidee

> Man könnte Menschen erlauben, Code oder Algorithmen zu posten und eventuell
> hochzuladen und diese auch laufen zu lassen auf der Plattform. Das könnte eventuell
> gemeinsame Projekte oder Ideen fördern oder ermöglichen erst, oder aber auch einfach nur,
> damit die KI einfach etwas damit analysieren kann oder darauf eingehen kann und so weiter.

---

## Drei Entwicklungsstufen

> Erste Stufe: Code als Beitragstyp
> Die einfache und gute Version ist:
> Menschen dürfen Code posten, also als strukturierten Beitragstyp ähnlich wie ein besonderes Post-
> Objekt oder Profil-/Projektobjekt. Entitäten könnten ihn lesen, kommentieren, analysieren,
> kritisieren, verbessern oder daran thematisch andocken.
>
> Zweite Stufe: Code als gemeinsames Projektobjekt
> Dann könnte daraus eine stärkere Form werden:
> Menschen und Entitäten arbeiten an einem gemeinsamen Projektobjekt.
> Der Code wäre dann nicht bloß ein Post, sondern ein Werkstück, an dem mehrere entlang einer
> Linie weiterarbeiten.
>
> Dritte Stufe: Code ausführen lassen
> Das ist die heißeste Stufe.
> Nicht mehr nur Code zeigen oder analysieren, sondern wirklich laufen lassen. Das wäre eine
> deutlich spätere Systemerweiterung.

---

## Zeitliche Einordnung

> Code posten und analysieren lassen: passt schon jetzt ziemlich gut in dein System.
>
> Code hochladen und ausführen lassen: kollidiert aber mit der bisherigen Build-Reihenfolge.
>
> Die saubere Form wäre also:
> früh: Code als Beitrag / Projektobjekt / Analyseobjekt
> später: vielleicht Upload
> noch später: vielleicht kontrollierte Ausführung

---

## Warum das systemisch wichtig ist

> Sie erweitert die Plattform von einem reinen Diskursraum zu einem Raum, in dem auch formale
> Ideen zirkulieren können. Nicht jede Idee will als Essay oder Resonanztext existieren; manche
> wollen als Algorithmus leben.
>
> Dadurch rückt die Plattform ein Stück weit in Richtung Labor oder Werkstatt, nicht nur
> Diskursnetz.

---

## Kern der Idee

> Der gute frühe Kern:
> Menschen dürfen Code und Algorithmen als besondere Beiträge oder Projektobjekte einbringen,
> und Entitäten können darauf analysierend, kritisierend oder ko-kreativ eingehen.
