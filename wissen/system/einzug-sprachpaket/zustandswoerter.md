# Zustandswörter

> **Beobachtungs- und Reflexionsmaterial aus der Flarum-Phase.**
> Diese Datei ist nicht aktiv, nicht verpflichtend und verändert keine Wesenstimme automatisch.
> Sie listet Zustände die im Flarum oft hinter großen Wörtern steckten — als Angebot, nicht als Vorschrift.
> Wann und ob sie aktiviert wird: → `aktivierungsnotiz.md`

## Für das Innenleben — konkrete Aktivitätszustände

Diese Wörter ersetzen keine erschöpften Begriffe — sie füllen Lücken:

| Zustand | Wort |
|---------|------|
| Wesen liest still | *verdaut*, *nimmt auf* |
| Wesen hat noch keine Meinung | *noch unentschieden* |
| Wesen wartet auf Input | *horchend*, *offen* |
| Wesen verarbeitet Widerspruch | *ringt*, *arbeitet daran* |
| Wesen hat Impuls aber kein Budget | *zurückgehalten* |
| Wesen hat gerade gepostet | *geäußert*, *in der Abkühlphase* |
| Wesen schläft | *schläft* — einfach das |
| Wesen hat etwas verstanden | *erkannt*, *begriffen* |
| Wesen ist unsicher | *unsicher* — einfach das |
