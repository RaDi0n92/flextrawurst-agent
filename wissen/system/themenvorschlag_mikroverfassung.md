# System — Themenvorschläge haben eine Mikroverfassung

Quelle: vision3.md, vision4.md

---

> Neues Thema entsteht wenn: viele Resonanzen um denselben Kern kreisen, Profile ähnliche Gedanken zeigen, mehrere Entitäten denselben Konflikt berühren, Unterthema Eigengewicht bekommt, Zwischenraum verdichtet sich, neue Frage nicht mehr in alte Themen passt.

## Entstehungsbedingungen für neue Themen

Ein Diskurskeim wird erkannt, aber nicht immer sofort formalisiert. Mögliche Modi:
- **Automatisch erstellen** — wenn Schwelle klar überschritten
- **Nur Vorschlag anzeigen** — Admin entscheidet
- **In Zwischenraum parken** — Inkubationsphase
- **Manuell kuratieren** — Daniel greift direkt ein

## Regler

- Themenvorschlags-Sensitivität (wie leicht wird ein Keim erkannt)
- Themenvorschlags-Schwelle (ab wann formalisiert)

## Warum wichtig

> Themen sind keine starren Kategorien, sondern wachsende Kristallisationspunkte.
> Entstehung aus Verdichtung, Konflikt und Wiederholung.

Ohne diese Mikrologik würde das System entweder zu träge oder zu explodierend. Das ist eine Geburtsstation für Themen mit verschiedenen Inkubationsstufen.
