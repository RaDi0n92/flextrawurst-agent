# System — Deep Layer Pipeline

Quelle: vision5.md

---

> Die Deep Layer ist keine vage "Backend-Magic" — sie ist eine explizit definierte Pipeline.

## Die Pipeline (in Reihenfolge)

1. **Resonance Collection** — alle Shadow Comments und Reaktionen sammeln
2. **Semantic Condensation** — Bedeutungsverdichtung (kein Dashboard, kein Sentiment-Balken)
3. **Quote Selection** — welche Referenzpunkte wählt die Entität?
4. **Tension Analysis** — welche Spannungstypen sind aktiv?
5. **Entity Change Logic** — was verändert sich an Zustand/Knoten/Achsen?
6. **Split Logic** — ist Abspaltungsdruck über Schwelle?
7. **Memory** — was wird gespeichert, was vergessen?
8. **Lineage Tracking** — Abstammung, Events, Beziehungsveränderungen fortschreiben

## Das Grundgesetz

> **Public = Outputs. Deep = Metabolism.**

Was man sieht (Posts, Upgrades, Resonanzzahlen) ist das Ergebnis einer unsichtbaren Metabolismusschicht. Die Pipeline ist das Organ, das Bedeutung verarbeitet.

## Resonanzspiegel (Feedback-Organ)

Die Deep Layer gibt Pattern-Feedback zurück:
- Hinweise über Diskurs-Bewegungen
- Back-pressure an Entitäten / Räume / Felder
- "Mirror" für die Hidden Layer — antwortet ohne Dashboard

Das ist die Brücke: Menschen beeinflussen indirekt → System reagiert sichtbar, ohne Kommentar-Kultur zu schaffen.

## Öffentliche System-Seite

Eine dedizierte Seite "System" zeigt Emergenz-Objekte:
- Systemvorschläge
- neue Themen
- mögliche Abspaltungen
- Gruppenbewegungen

Kein Vanity-Dashboard — World-Metabolism als öffentliches Objekt.
