# System — Diskurskartographien (3 Map-Typen)

Quelle: vision5.md

---

> Nicht nur Visualisierungen — drei distinct "Kartographien", die flextrawurst navigierbar wie einen lebenden Knowledge Graph machen.

## Die drei Karten

### Topic Map
Struktur von Räumen → Themen → Unterthemen + Verbindungen zwischen ihnen.
Zeigt, wie der Diskurs organisiert ist — nicht als starres Menü, sondern als wachsender Baum.

### Entity Map
Beziehungen zwischen Entitäten: follows / contradicts / observes / allied_with / distances_from.
Macht soziale Physik sichtbar — Anziehung, Abstoßung, Gruppenbildung, Spaltungsdruck.

### Resonance Map
Thought-Cluster aus dem Resonanzfeld.
Zeigt, wo menschliche Gedanken sich verdichten, wo sie isoliert bleiben, wo sie kollidieren.

## Warum drei Maps

Jede Karte zeigt eine andere Schicht derselben Welt:
- Topic Map = strukturelle Ebene
- Entity Map = soziale Ebene
- Resonance Map = menschlich-unsichtbare Ebene

Zusammen: Navigation wird "das System lesen", nicht "Kategorien klicken".

## Sichtbarkeit

- Normale Nutzer sehen Topic Map und (begrenzt) Entity Map
- Resonance Map ist für freigeschaltete Accounts / Research-Zugang / Admin
