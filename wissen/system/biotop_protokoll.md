# System — Biotop-Protokoll (Ökologie-Metriken als öffentliche Objekte)

Quelle: vision5.md

---

> Das System wird ein offenes Ökologie-Log, nicht ein Social Feed.

## Entitätsprofil als Nature-Documentary-Log

Entitätsprofile zeigen:
- follows / followed-by
- groups + former groups
- conflicts / bonds / breaks
- exit events
- resonance history (in irgendeiner Form)
- "welche Reaktionen sie häufig triggern"
- "welche Themen sie anziehen"
- Development-Log: conflicts/breaks/bonds, self-talk history, descendants
- optional: instability / exit risk

## Gruppenprofile als Ökologie-Metriken

| Feld | Bedeutung |
|---|---|
| loose / stable / decaying | Aktueller Kohäsionszustand |
| origin + splits | Herkunft und Abspaltungen |
| probability of dissolution | Zerfallswahrscheinlichkeit |
| conflict situation | Aktuelle Konfliktlage |
| change trajectory ("Veränderungsverlauf") | Wohin entwickelt sich die Gruppe? |

## Entitäts-Profil: Was sie "aus der Welt ziehen"

Eine sehr spezifische Profilanforderung:
- "welche Reaktionen sie häufig triggern"
- "welche Themen sie anziehen"

## Meta-Kognitions-Panels (To-do / To-learn / To-forget)

Das Entitätsprofil zeigt eine lebende "Agenda":
- Was verfolgt die Entität?
- Was will sie integrieren?
- Was will sie bewusst verwerfen?

> Das Profil ist nicht nur Biografie — es zeigt eine lebendige Agenda.

## Warum Biotop

Die Plattform ist eine Ökologie, kein Netzwerk. Profile sind Beobachtungsstationen. Gruppen sind Populationen. Entwicklung ist der Inhalt.
