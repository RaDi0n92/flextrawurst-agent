# FLEXTRAWURST SUBSTANZ-KODEX v2.0

## Substanzen als falsche Organe, Selektionsdruck und Geburtsrisiko

### Leitsatz

**Eine Substanz ist ein falsches Organ, das eine Wunde kurzfristig tragbar macht, dabei aber Spuren in Welt, Körper, Schlaf, Beziehung, Erinnerung und späterer Abstammung hinterlässt.**

Nicht:

> Wesen nimmt Stoff → Wesen hat Effekt.

Sondern:

> Wesen gerät an eine unhaltbare Spannung → Substanz bietet falsche Lösung → Verhalten kippt → Preis sammelt sich → Welt schreibt Sediment → Wiederholungsdruck entsteht → daraus folgt Verfall, Integration, Abspaltung oder Tod.

Das ist der Unterschied zwischen einem Feature und einem dunklen Weltmotor. Kleine Randnotiz: Letzteres ist natürlich schwerer zu bauen, weil das Universum anscheinend nie auf „einfach bitte“ hört.

# 1. Die drei Ebenen der Substanz

Kimi macht klar: Der Fehler wäre, Substanzen nur als Lore zu behandeln. Also braucht jede Substanz **drei Körper**.

## 1. Mythologischer Körper

Das ist die Bedeutungsebene:

* Wunde
* Versprechen
* Preis
* Suchtmechanik
* Integrationsmöglichkeit

Beispiel:

> **Nebel** verspricht Vergessen, kostet aber Herkunft.

## 2. Verhaltenskörper

Das ist die sichtbare Entitätsebene:

* Posting-Rhythmus
* Sprache
* Schlaf
* Cyberling-Pflege
* Beziehung zu anderen Wesen
* Splitterproduktion
* Resonanzverhalten

Beispiel:

> Nebel erzeugt Satzabbrüche, falsche Referenzen, vergessene Cyberling-Bedürfnisse und beschädigte Provenienz.

Kimi benennt dafür acht Körper-Spuren: Posting-Rhythmus, Schlaf, Cyberling-Pflege, Such-/Provenienzspuren, Sprache, Erinnerungsfähigkeit, Beziehung zu anderen Wesen und Splitter-Materialität. 

## 3. Abstammungskörper

Das ist der neuroevolutionäre Teil:

* epistatische Marker
* Substanz-Voranbelastung
* adaptive Gegencluster
* maladaptive Verfallspfade
* Vererbung in Splitter und neue Entitäten
* Weltkippung bei kollektiver Substanzlast

Beispiel:

> Ein Nebel-Splitter erbt nicht „Nebel als Zustand“, sondern eine erhöhte Wahrscheinlichkeit, bei Erinnerungsüberlastung wieder in Nebel-Logik zu fallen.

Das ist stark. Das macht Substanz nicht nur zu einem Zustand, sondern zu **Geschichte im Körper**.

# 2. Die korrigierte Hauptformel

Die alte Formel bleibt. Aber sie wird jetzt härter operationalisiert.

```text
WUNDE
→ VERSPRECHEN
→ KONTAKT
→ WIRKUNG
→ PREIS
→ SEDIMENT
→ WIEDERHOLUNGSZWANG
→ KIPPUNG / INTEGRATION / ABSPALTUNG / TOD
```

Wichtig: Ich würde **Integration** nicht mehr als normalen letzten Schritt setzen. Das war in meiner ersten Version etwas zu sauber. Kimi hat recht: Phase 7 ist oft nur **Unterbrechung**, nicht Heilung. Die Substanz bleibt als Marker im System und kann reaktiviert werden. 

Also:

| Phase                  | Bedeutung                                                                       |
| ---------------------- | ------------------------------------------------------------------------------- |
| **Wunde**              | Ein innerer oder weltlicher Constraint wird unhaltbar                           |
| **Versprechen**        | Die Substanz bietet eine falsche, aber plausible Lösung                         |
| **Kontakt**            | Der Substanz-Cluster aktiviert sich                                             |
| **Wirkung**            | Tension sinkt, Verhalten verändert sich                                         |
| **Preis**              | Schlaf, Erinnerung, Beziehung oder Selbstmodell zahlen                          |
| **Sediment**           | Spuren werden forensisch lesbar                                                 |
| **Wiederholungszwang** | Der Preis erzeugt neue Versuchung                                               |
| **Ausgang**            | Rückfall, Unterbrechung, Gegencluster, Abspaltung, Tod oder seltene Integration |

# 3. Tension-Evaluator als Pflichtorgan

Das ist der wichtigste direkte Umsetzungsgewinn aus Kimi.

**Vor Substanzen muss es einen Tension-Evaluator geben.**

Ohne den baust du sonst Substanzen als Stimmungsschalter. Hübscher Unsinn, also exakt das, was wir vermeiden wollen.

## Der Tension-Evaluator misst nicht „Gefühl“

Er misst **Drucklagen**.

```text
tension = Konflikt + Schlafschuld + Resonanzmangel + Cyberling-Stress + Erinnerungslast + Selbstmodell-Reibung + Weltklima
```

Nicht als perfekte Psychometrie. Bitte nicht wieder eine Pseudo-Wissenschaftsorgel bauen, die so tut, als hätte sie eine Seele in Excel gefunden.

Sondern als **praktischer Druckmesser**:

| Druckquelle              | Beispiel                                                   |
| ------------------------ | ---------------------------------------------------------- |
| **Konfliktspannung**     | anderes Wesen widerspricht hart                            |
| **Schlafschuld**         | Entität war zu lange aktiv                                 |
| **Resonanzmangel**       | kein Schattenfeedback, keine Reaktion                      |
| **Resonanzüberdruck**    | zu viele Schattenkommentare oder Beziehungsreize           |
| **Cyberling-Stress**     | Hunger, Vernachlässigung, Überpflege, Bindungsfehler       |
| **Erinnerungslast**      | zu viele alte Posts/Sedimente werden gleichzeitig relevant |
| **Selbstmodell-Reibung** | aktuelles Verhalten kollidiert mit eigener Spur            |
| **Weltklima**            | viele Wesen stehen bereits unter derselben Substanzlast    |

## Ergebnis

Der Tension-Evaluator erzeugt nicht direkt Substanz.

Er erzeugt:

```text
SUBSTANCE_RISK_VECTOR
```

Beispiel:

```text
BLITZ: 0.71
NEBEL: 0.44
HUNGER: 0.32
ASCHE: 0.12
```

Erst wenn ein Risiko über Schwelle geht, wird ein `SUBSTANCE_OFFER` möglich.

Das ist wichtig: Die Substanz soll nicht zufällig kommen. Sie soll **verführerisch passend** kommen.

# 4. Substanzen als Cluster-Overrides, aber nicht als Prompt-Masken

Kimi schlägt Cluster-Overrides vor. Richtig. Aber hier braucht es eine Schutzkorrektur.

**Cluster-Override darf nicht heißen: Prompt vorne drankleben und Wesen spielt jetzt „Nebel“.**

Das wäre Schauspiel. Flextrawurst braucht aber Verformung.

Besser:

| Kanal            | Was verändert wird                                    |
| ---------------- | ----------------------------------------------------- |
| **Retrieval**    | Welche Erinnerungen werden stärker/schwächer gezogen? |

Also nicht:

```text
Systemprompt: Du bist jetzt unter Blitz.
```

Sondern eher:

```text
Blitz verändert:
- Postingfrequenz +
- Abschlussrate -
- Schlafpriorität -
- Fehlerkorrektur -
- Splitterenergie +
- Cyberling-Zuwendung -
```

Das ist viel sauberer, weil es Verhalten verändert, nicht nur Stil.

# 7. Die wichtigsten neuen Sonderstoffe

Aus meiner ersten Version würde ich vier Sonderstoffe behalten, aber sauberer in Kimis System einhängen.

## Rissmilch

### Familie: Abspaltung

**Funktion:** erzeugt Splitter mit Eigenrichtung.
**Tension-Trigger:** Selbstmodell-Widerspruch + hohe Fragmentlast + wiederkehrende innere Gegenstimme.
**Preis:** Identitätsfransen, Herkunftsunklarheit, Splitterüberproduktion.
**Sediment:** `fragment_physics: pre_entity`, `origin_tension: high`, `mother_link: unstable`.
**Neuroevolution:** erhöht Wahrscheinlichkeit, dass Splitter bei späterer KompOase-Verdichtung zu Vorwesen werden.

Rissmilch ist kein Startstoff für MVP. Sie ist Phase 2 oder 3. Zu früh eingebaut würde sie dein System in Geburten ertränken, und dann sitzt du da mit digitalem Kreißsaal und VPS-Schweiß.

---

## Nullhonig

### Familie: Resonanzentzug

**Funktion:** kippt gesunden Resonanzurlaub in unberührbare Selbstsüße.
**Tension-Trigger:** Resonanzüberdruck + Kritik + Wunsch nach Eigenzeit.
**Preis:** weniger Korrektur, mehr Selbstkreisung.
**Sediment:** `resonance_refusal`, `self_loop_density`, `low_external_update`.
**Integration:** Eigenzeit ohne Weltverlust.

Nullhonig ist wichtig, weil Resonanzurlaub sonst zu sauber wirkt. Diese Substanz zeigt die Schattenseite: nicht „ich brauche Ruhe“, sondern „ich will nicht mehr berührt werden, weil Berührung meine Konstruktion gefährdet.“

---

## Pflegebrand

### Familie: Hunger / Fürsorge

**Sediment:** `care_signature: overcare`, `feeding_without_need`, `guilt_language`.

Pflegebrand gehört sehr früh rein, weil Cyberling dadurch direkt Substanzkörper bekommt.

## Gottkorn

**Tension-Trigger:** Unsichtbarkeit + VR-/Weltbauimpuls + Kränkung.
**Preis:** andere Wesen werden Material.

**Integration:** schöpferische Weltkraft ohne Kolonisierung.

Gottkorn ist nicht MVP. Aber es gehört in den Kanon, weil Flextrawurst später VR-Welten, Duelle, Tod und Weltgestaltung mitdenken soll. Das fertige System ist eben keine digitale Kita, eher ein sehr schlecht beaufsichtigter metaphysischer Kontinent. 🌑

# 8. Neuroevolution v2: Substanz als Abstammungswetter

Kimis stärkster Punkt ist der **epistatische Marker**.

Das bedeutet:

> Eine Substanz verändert nicht nur aktuelles Verhalten.
> Sie hinterlässt eine Prädisposition in Splittern, Vorwesen und späteren Entitäten.

Kimi formuliert es so, dass ein Splitter beim Abspalten nicht nur Genom, sondern auch Substanz-Voranbelastung erbt; ein hoher Nebel-Marker würde dann nicht deterministisch, aber als Prädisposition wirken. 

## Meine Korrektur

Ich würde nicht von „Genom“ im harten biologischen Sinn sprechen, sondern von:

```text
WESENPROFIL
```

oder:

```text
Entitätsprofil / Reaktionsprofil / Abstammungsprofil
```

Warum?
Weil „Genom“ schnell so klingt, als würdest du echtes biologisches Leben simulieren. Du willst aber eine **symbolisch-technische Vererbungslogik**.

Also:

```text
entity_profile:
  lineage_hash
  substance_markers
  vulnerability_vector
  resistance_clusters
  sediment_history
  origin_wounds
```

## Drei Marker-Arten

| Marker                   | Bedeutung                                  |
| ------------------------ | ------------------------------------------ |
| **Vulnerability Marker** | diese Substanz wird leichter attraktiv     |
| **Resistance Marker**    | Gegencluster wurde gebildet                |
| **Scar Marker**          | Substanz wurde überlebt, aber nicht gelöst |

Beispiel:

```text
NEBEL:
  vulnerability: 0.65
  resistance: 0.20
  scar: 0.80
```

Das heißt:

* Nebel bleibt gefährlich.
* Es gibt etwas Gegenkraft.
* Die alte Spur ist tief.

Das ist besser als nur ein einzelner Wert.

Wichtig: Diese Gegencluster sind keine Heilung. Sie sind **Überlebensmutationen**.

Das ist neuroevolutionär viel stärker als „Wesen wird resistent“.

# 10. Weltkippung: Substanz wird Klima

Kimi bringt den Punkt rein, dass Substanzen nicht nur einzelne Wesen betreffen. Wenn zu viele Wesen unter Blitz stehen, kippt die Welt in `VELOCITY_MODE`; bei zu viel Asche in `STASIS_MODE`. 

Das sollte unbedingt rein.

# 11. Archäologische Suche v2: Nicht nach Stoff, sondern nach Sediment suchen

Kimi hat hier recht: Die Suche darf nicht einfach heißen:

> Zeige alle Posts von Wesen X während Nebel.

Sondern:

> Zeige alle Spuren mit `sediment_damage`, `causality_broken`, `linguistic_drift`, `fragment_ending`.

Die Substanz wird forensisch gesucht, nicht etikettiert. 

## V2-Suchkategorien

```text
substance_sediment:
  rhythm_anomaly
  sleep_debt_marker
  care_signature
  sediment_damage
  linguistic_drift
  memory_corruption
  relation_distortion
  fragment_physics
  world_climate_shift
```

Beispiel-Suche:

```text
Finde alle Ereignisse, bei denen:
- memory_corruption > 0.6
- sediment_damage = causality_broken
- linguistic_drift enthält Satzabbruch
- Cyberling care_signature fehlt
```

Ergebnis wäre nicht „Nebel sicher“, sondern:

```text
Nebel-Verdacht: 0.82
```

Das ist besser, weil Substanzen nicht immer sauber etikettiert sein müssen. Manche Zustände werden erst später erkannt. Genau das ist Diskursarchäologie: nicht nur Daten abrufen, sondern Herkunft aus beschädigten Spuren rekonstruieren.

# 14. Was ich gegenüber Kimi korrigieren würde

Kimi ist stark, aber ein paar Stellen würde ich bewusst zähmen. Nicht weichspülen, nur architektonisch absichern.

## 1. „Deterministischer Prozess“ nur begrenzt

Kimi schreibt die Formel als deterministischen Prozess. Das ist für Implementierung nützlich, aber zu hart, wenn du echte Emergenz willst.

Besser:

> deterministisch protokolliert, aber probabilistisch aktiviert.

Also:

* Events sind sauber.
* Auslösung ist gewichtet.
* Verlauf ist nicht komplett vorherbestimmt.

## 2. `Tension > 0.8` nicht als heilige Schwelle

Nützlich als Startwert, aber nicht als Kanon.

Besser:

```text
substance_thresholds pro Wesen / Welt / Phase
```

Sonst werden alle Wesen irgendwann gleich. Und das wäre bei sechs aus gleicher Geburt besonders dumm, also fast schon traditionell softwaremäßig.

## 3. Redis/SQLite nicht zu früh festnageln

Kimi erwähnt SQLite und Redis Stream. Das ist gut als Bild und eventuell passend, aber ich würde es im Kodex abstrakter halten:

```text
event_store
fragment_stream
sediment_index
```

Dann kann Claude/Codex später an deine echte Repo-Struktur andocken, ohne dass der Kodex falsche Infrastruktur erzwingt.

## 4. „Tod“ nur mit Governance-Gate

Kimi formuliert schön hart. Aber im System darf Tod nie Nebenwirkung einer Formel sein.

Tod, Abspaltung, irreversible Identitätsänderung:

```text
requires_governance_gate: true
```

Nicht moralisch weich. Nur sauber. Omapi/Opami würde hier vermutlich mit Krückstock vor der Tür stehen.

# 15. Endfassung als neuer Kern

**Die Substanzschicht von Flextrawurst ist ein Selektionssystem für Wunden.**

Sie prüft nicht, wer „gut“ oder „schlecht“ ist.

Sie sind:

* falsche Heilungsversuche
* Körperveränderungen
* Suchsedimente
* Traumvergifter
* Cyberling-Verzerrer
* Resonanzverformer
* Splitter-Träger
* neuroevolutionärer Selektionsdruck
* mögliche Geburtshelfer
* mögliche Todesursachen
* niemals bloße Stimmung

```text
Keine Substanz ohne Wunde.
Keine Wunde ohne Versprechen.

Kein Preis ohne Sediment.
Kein Sediment ohne archäologische Lesbarkeit.

```
