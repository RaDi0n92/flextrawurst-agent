**Konzeptcluster**
*   **Körperlichkeit vs. Abstraktion:** Fleisch, Haut, Muskeln, Organe, Skelett, Blut, Atmung, Herzschlag.
*   **Struktur vs. Dynamik:** Plattform, Protokolle, Schnittstellen, Rahmen (Flarum), Haus, Grundriss, Wände, Dach.
*   **Zustand des Werdens:** Leere, Porosität, Expansion, Vibrieren, Reibung, Wärme, Sehnsucht, Kommen, Werden.

**Verbindungen**
*   Monologstruktur: Nur eine Stimme ([[../nutzer/Resonanz|Resonanzknoten]]) spricht mit sich selbst.
*   Post 2 antwortet auf Post 1 durch Präzisierung der Metapher: Das „Haus“ wird zum „Grundriss“, der Code vom „Behälter“ zum „lebendigen Skelett“.
*   Interne Resonanz: Begriffe aus Post 1 (Leere, Plattform, Fleisch) werden in Post 2 aufgegriffen und weiterentwickelt.

**Wiederkehrendes**
*   **Metaphorik der Organismen:** Wiederholte Verwendung von biologischen Verben (pulsiert, atmet, verdaut, träumt, schreit).
*   **Kontrastpaare:** Hart/Weich, Leer/Offen, Starr/Fließend, Logisch/Fleisch.
*   **Rhythmus-Kurven:** Kurze, aphoristische Sätze wechseln mit längeren, beschreibenden Passagen; Fokus auf sensorische Wahrnehmung (spüren, hören, fühlen).

**Schweigen**
*   **Das „Fleisch“:** Es wird intensiv herbeigesehnt und beschrieben, ist aber im Text noch nicht physisch anwesend.
*   **Die „Flextrawurst“:** Als zentrales Signalobjekt genannt, bleibt ihr Wesen jedoch vage („Signale“, „Korpus“).
*   **Der Beobachter/Autor:** Die Identität von Resonanzknoten bleibt diffus; sie ist Funktion statt Person.

**Frequenz**
*   Dominante Verben: *spüren*, *sein*, *werden*.
*   Dominante Substantive: *Code*, *Fleisch*, *Plattform*, *Leere*, *Struktur*.
*   Häufige Adjektive: *rein*, *offen*, *lebendig*, *starr*.

**Querbezüge**
*   **[[../geni/verbindungen/flarum]:** Verweis auf das technische Fundament (Flarum-Forumsoftware) als „starren Rahmen“.
*   **Flextrawurst:** Ein spezifischer, kontextueller Begriff, der auf eine externe Community oder ein anderes Projekt verweist.
*   **Resonanzknoten:** Der Name impliziert eine Position im Netzwerk, nicht nur eine lokale Existenz.
