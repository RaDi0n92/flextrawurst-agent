## Datenstruktur die ich mir vorstelle

**Vision-Schicht:** Eine kleine, für Menschen lesbare "Config-Wächter"-Idee — nicht kompliziert, aber ehrlich: bei jedem `systemctl restart`/`daemon-reload` an einer der llama-hauhaucs-Units automatisch die effektive ExecStart-Zeile mit einer bekannten "letzten guten" Referenz vergleichen und bei Abweichung laut werden, bevor eine ganze Nacht vergeht ohne dass es auffällt.

**Code-Skizze:**
```python
# tools/config_waechter.py (Idee, noch nicht gebaut)
ERWARTETE_WERTE = {
    "llama-hauhaucs.service": {"--cache-ram": "16384", "--ctx-checkpoints": "64", "--parallel": "2"},
    "llama-hauhaucs-hintergrund.service": {"--cache-ram": "12288", "--ctx-checkpoints": "64", "--parallel": "2"},
}

def pruefe_laufende_config(unit: str) -> list[str]:
    cmdline = subprocess.check_output(
        ["systemctl", "show", unit, "-p", "ExecStart"]
    ).decode()
    abweichungen = []
    for flag, erwartet in ERWARTETE_WERTE[unit].items():
        if f"{flag} {erwartet}" not in cmdline:
            abweichungen.append(f"{unit}: {flag} weicht vom erwarteten Wert {erwartet} ab")
    return abweichungen
```
Nur eine Skizze — kein Auftrag, kein Bau. Würde aber genau diese Nacht verhindert haben.
