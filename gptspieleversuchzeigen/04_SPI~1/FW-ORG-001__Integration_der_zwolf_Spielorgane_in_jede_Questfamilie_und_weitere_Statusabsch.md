# Integration der zwölf Spielorgane in jede Questfamilie

Jeder Questdatensatz besitzt zwölf Organfelder. Nicht jedes Organ muss in einer Mikroquest gleich stark aktiv sein. Kein Organ darf aber strukturell ausgeschlossen sein.

| Organ | Questfunktion |
|---|---|
| Skyrim | verkörperte Erkundung, pausierbares Ordnen, tiefe Nebenpfade, gebrauchsbasiertes Lernen |
| Grand Theft Auto | dichte Stadt, Verkehr, Fahrzeuge, Bevölkerung, Geheimnisse, Eskalation |
| Minecraft | Stoffwelt, Untergrund, Erze, Crafting, Bauen, Reparatur, Automatisierung |
| Fortnite | editierbare Baukörper, Creatorwelten, gemeinsame Ereignisse, Konzerte, Veröffentlichung |
| Dwarf Fortress | lange Geschichte, Artefakte, Kausalität, emergente Nachwelt |
| RimWorld | Beziehungen, Bedürfnisse, Krisen, Verletzlichkeit, kulturelle Unterschiede |
| Kenshi | autonome Welt, kein Auserwählter, Fraktionen und Fortgang ohne Spieler |
| Disco Elysium | innere Stimmen, Ideologie, Dialogtiefe, widersprüchliche Selbstdeutung |
| Shadows of Doubt | Routinen, Geheimnisse, Ermittlung, individuelle Bewohnerdaten |
| Project Zomboid | Zeit, Materialverbrauch, Verletzung, Überleben, bleibende Weltspuren |
| No Man’s Sky | große Entdeckungsräume, ungewöhnliche Orte, Fernreisen, verteilte Welten |
| Pokémon-Community-Wirkung | Kennenlernen, Katalog, Gemeinschaft und Bindung ohne Besitzlogik |

## Aktivierungsregel

- Mikroquest: mindestens 3 aktive Organe, 3 anschlussfähige, 6 latent dokumentierte.
- Mesoquest: mindestens 5 aktive Organe.
- Makroquest: mindestens 8 aktive Organe.
- Große Questlinie: alle 12 Organe müssen mindestens einmal spielentscheidend werden.

## Just-Cause-2-Zusatzorgan

Traversal durch Haken, Fallschirm, Schwung und Fahrzeuge ist eine querliegende Bewegungsgrammatik. Es darf Erkundung, Flucht, Rettung, Bossbegegnung, Bau und Umweltkonflikt verändern, ohne Questlösungen auf Geschicklichkeit zu reduzieren.
