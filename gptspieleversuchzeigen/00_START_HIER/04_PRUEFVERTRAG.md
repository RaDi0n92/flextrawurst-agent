# Prüfvertrag

Vor Freigabe müssen gleichzeitig gelten:

- exakt 333 Markdown-Dateien,
- keine gebrochenen relativen Markdown-Links,
- alle 146 kanonisch verwendeten v21-/v22-Quelldateien vollständig durch Segmentmarker rekonstruiert,
- R21 bis R26 wortgetreu erhalten,
- alle drei ursprünglichen Uploadarchive mit unverändertem SHA-256 enthalten,
- kein Markdown-Monolith über 55 KB,
- keine inhaltlichen Dubletten im kanonischen Körper,
- jeder Knoten besitzt mindestens einen eingehenden und einen ausgehenden Netzwerkbezug.
