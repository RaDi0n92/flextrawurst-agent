# Navigation und Linklogik

Jede Markdown-Datei besitzt:

- eine stabile Knoten-ID,
- einen Rücklink zum Themenindex,
- Vorgänger und Nachfolger im selben Themenordner,
- Querverweise auf inhaltlich verwandte Knoten,
- Versions- und Quellbezüge,
- maschinenlesbare Kanten im Netzwerkindex.

Inhalte werden nicht für jede Sichtachse kopiert. Versionen, Themen, Rohtexte und Tests zeigen über Links auf denselben kanonischen Körper.
