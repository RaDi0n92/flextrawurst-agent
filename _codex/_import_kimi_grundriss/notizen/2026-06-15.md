# 2026-06-15 — TTS-Fix: lange Antworten satzweise vorlesen

## Was passiert ist

Daniel meldete, dass TTS bei langen Antworten abbricht. Mehrere Iterationen:

1. Backend-Chunking mit MP3-Konkatenierung → Browser spielte nur ersten Teil ab (ID3-Tag-Problem).
2. Frontend-Truncation auf 600 Zeichen entfernt → Text war vollständig, aber einzelner Request für 2.500 Zeichen dauerte 35 Sekunden und brach im Browser ab.
3. Audio-Objekt global gehalten → half nicht gegen das Timeout-Problem.
4. **Satzweise Wiedergabe im Frontend** → Text wird in ~400-Zeichen-Chunks aufgeteilt, nacheinander abgespielt.

Ergebnis: Daniel bestätigte erstmals, dass ein langer Text komplett vorgelesen wurde (mit kurzen Pausen dazwischen).
