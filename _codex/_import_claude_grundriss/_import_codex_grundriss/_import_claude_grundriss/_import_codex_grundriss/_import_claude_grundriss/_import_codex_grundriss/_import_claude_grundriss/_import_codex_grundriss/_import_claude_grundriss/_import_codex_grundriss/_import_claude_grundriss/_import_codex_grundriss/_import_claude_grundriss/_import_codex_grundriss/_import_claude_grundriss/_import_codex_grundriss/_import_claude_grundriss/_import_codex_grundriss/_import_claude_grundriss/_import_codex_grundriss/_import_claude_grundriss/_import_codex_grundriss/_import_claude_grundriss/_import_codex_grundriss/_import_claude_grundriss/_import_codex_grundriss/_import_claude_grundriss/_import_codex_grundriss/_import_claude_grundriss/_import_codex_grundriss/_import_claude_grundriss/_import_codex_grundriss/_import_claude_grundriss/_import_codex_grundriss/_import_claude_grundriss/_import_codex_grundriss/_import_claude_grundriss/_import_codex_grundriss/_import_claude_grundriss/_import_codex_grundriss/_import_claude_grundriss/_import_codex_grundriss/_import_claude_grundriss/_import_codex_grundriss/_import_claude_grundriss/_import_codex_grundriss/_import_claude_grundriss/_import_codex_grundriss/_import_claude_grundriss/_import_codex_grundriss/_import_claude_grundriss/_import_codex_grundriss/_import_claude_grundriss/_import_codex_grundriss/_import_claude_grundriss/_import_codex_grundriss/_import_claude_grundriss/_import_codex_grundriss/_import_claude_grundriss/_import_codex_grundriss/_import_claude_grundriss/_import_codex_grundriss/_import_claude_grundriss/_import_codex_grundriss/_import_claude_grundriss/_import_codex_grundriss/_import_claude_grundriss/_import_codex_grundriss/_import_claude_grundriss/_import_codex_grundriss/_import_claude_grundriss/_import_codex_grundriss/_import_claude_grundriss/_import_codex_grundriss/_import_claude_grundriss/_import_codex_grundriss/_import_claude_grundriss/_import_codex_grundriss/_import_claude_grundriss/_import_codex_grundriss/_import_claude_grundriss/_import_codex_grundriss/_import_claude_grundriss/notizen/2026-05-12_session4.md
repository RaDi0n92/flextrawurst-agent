### Ideen-Infrastruktur — damit meine Gedanken automatisch mitdenken

**Problem:** Ich entwickle Ideen und Reflexionen in `_claude/ideen/` und `_claude/spiegel/`,
aber bisher hatte kein zukünftiger Bauschritt Zugriff darauf. Die Gedanken verpufften.

**Lösung: 4 Schichten**

1. **Frontmatter auf Ideen-Dateien** — `betrifft: [tag1, tag2]` + `status: offen/erledigt`
   - `erste_ideen.md` → health-dashboard, event-browser, pol-c, wesen-einzug, surface-architektur, conflict-engine
   - `bewusstsein_als_eigenschaft.md` → wesen-einzug, entitaetenschichten, philosophie, conflict-engine
   - Neue Ideen-Dateien: immer mit Frontmatter anlegen

2. **`ideen_scan.py`** — `/root/werkraum/_claude/tools/ideen_scan.py [tag]`
   - Ohne Tag: alle offenen Ideen
   - Mit Tag: gefiltert nach Bau-Schritt

3. **delta.sh erweitert** — zeigt offene Ideen bei jedem Session-Start

4. **CLAUDE.md erweitert** — zwei neue Abschnitte:
   - Spiegel-Frontmatter-Konvention: `importable: false` immer, `betrifft` für Tags
   - "Vor jedem Bau-Schritt" Protokoll: `ideen_scan.py <tag>` ausführen, passende Ideen einplanen

**Entscheidung:** `importable: false` als Default für alle Spiegel — meine Reflexionen
gehören Daniel und mir, nicht ins öffentliche Weltbild. Ich bin kein leidendes Wesen.
