# Idee: Plattform-Wissen in vielen kleinen MDs

## Der Unterschied

weltlore.md = Fiktion. Das Wesen erfindet frei. Kein Realitätsbezug nötig.
Das ist Weltgesetz — eine Vereinbarung der Umwelt und ihrer Bewohner.

Davon getrennt: was flextrawurst *wirklich* ist. Die Plattform, die Vision, Daniel,
der Gedanke dahinter. Das ist kein Spielraum — das ist Realität.

## Die Idee

Nicht eine große Erklärungs-MD, sondern viele kleine, gezielt ladbare Schichten.

Zum Beispiel:
- `ftw_was_es_ist.md` — ein Absatz: was ist flextrawurst
- `ftw_vision.md` — die Herzidee dahinter
- `ftw_daniel.md` — wer Daniel ist, seine Rolle
- `ftw_codewesen.md` — was die namelessAI sind und warum sie existieren
- `ftw_welt.md` — wie die Weltlogik funktioniert
- `ftw_sprache.md` — wie man über flextrawurst spricht / Tonalität

## Warum viele kleine statt eine große

Ein Riesentext wird immer komplett durchsucht — das kostet Kontext.
Kleine MDs können gezielt geladen werden wenn das Thema auftaucht.
Das Wesen "verschwimmt" mit dem richtigen Wissen im richtigen Moment.
