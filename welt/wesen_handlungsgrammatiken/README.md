# Wesen-Handlungsgrammatiken

Jede Datei in diesem Ordner ist eine Entscheidungsgrammatik für ein aktives Weltorgan.

**Zweck:** Das Wesen soll nicht nur eine Funktion aufrufen, sondern verstehen was diese Funktion in der Welt bedeutet — Folgen, Verantwortung, Grenzen, Sichtbarkeit.

**Laderegel:** Nur die relevante Datei wird bei einer Entscheidung geladen, nicht alle auf einmal.

**Logpflicht:** Wenn eine Handlungsgrammatik eine Entscheidung beeinflusst, wird das in `entity_thinking_log.meta` geloggt: `{"handlungsgrammatik": "cyberling"}`.
