## Was gemacht wurde (chronologisch)

### 1. JS Parse-Fehler in build_surface.ts
**Bug:** `\n→ ` in einem TypeScript Template-Literal war ein echter Zeilenumbruch im generierten JS → gesamtes Script-IIFE (450 Zeilen) schlug beim Parsen fehl → `scvOpen`, `scrInit`, `scvFilter`, `dkstFilter` alle undefined → alle Buttons in SCREENS und DENKEN-Tab tot.
**Fix:** `'\n→ '` → `'\\n→ '` in build_surface.ts.

### 2. SSE Connection Leak — API komplett blockiert
**Bug:** `sel.select([conn], [], [], 30.0)` in `denkstream_api.py` lief direkt im async Generator → blockierte den asyncio Event-Loop bei JEDER SSE-Verbindung → 399 CLOSE_WAIT-Zombies → alle API-Calls gaben 504.
**Fix 1:** `welt-api` neugestartet (sofortige Entlastung).
**Fix 2:** `sel.select` über `await loop.run_in_executor(None, _poll_once)` in Thread-Pool ausgelagert → Event-Loop bleibt frei. Timeout 30s → 0.5s. Datei: `/root/werkraum/welt/denkstream_api.py`.

### 3. Fehlende Tabs wiederhergestellt
Zwischen Commits `a4bbf6cd366f` → `28ff24abc4e5` wurden ARCHÄOLOGIE, CYBERLINGE, SPLITTER, ZITATE, SCHATTEN als standalone Tabs entfernt.
**Fix:** Aus altem Commit extrahiert und neu in `build_surface.ts` als Generator-Funktionen + CSS + JS implementiert.

### 4. CSS Fonts/Farben auf richtigen Stand
Body-Font von `'Courier New'` zurück auf `var(--font-body)` = Segoe UI / Roboto. Text-Farben aufgehellt: `--t-mid:#5ab0c0`, `--t-bright:#a0e0f0`. Font-Size 16px.

### 5. Gruppen-Backup wiederhergestellt
Die `generateGruppenView()` war durch ein Keim/Knoten-System ersetzt worden (ohne Chat/Posts/Polls). Aus Backup-Commit (`a4bbf6cd366f`) extrahiert und wiedereingesetzt. Das Split-Panel mit Topics/Posts/Umfragen/Chat-Sidebar ist zurück.
**Achtung Fallstrick:** Die alte HTML hatte `split('\n')` → beim Einfügen ins Template-Literal wurde `\n` zu echtem Zeilenumbruch → zweiter Parse-Fehler. Fix: Python `html.replace('\\', '\\\\')` vor Einfügen.

### 6. Substanzschichten lesbar gemacht
Die unteren Karten (Rissmilch, Nullhonig, Pflegebrand, Gottkorn) hatten hardcodierte ultra-dunkle Inline-Farben (`color:#3a1a2a` etc.) auf `sub-card-kanal` und `sub-card-desc`. Fix: Inline-Styles entfernt, CSS-Klassen auf helle Werte gesetzt.

## Was mich noch beschäftigt

Die Template-Literal-Falle in build_surface.ts: Jedes mal wenn neues HTML mit JS-Strings in eine Template-Literal-Funktion eingefügt wird, müssen alle Backslash-Sequenzen (`\n`, `\t`, `\r`, `\\`) verdoppelt werden. Das ist nicht dokumentiert und wird immer wieder passieren.
